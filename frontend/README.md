# Lazis PLN Batam — Frontend

Next.js (App Router) + Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `app/` — routes (App Router). `app/page.js` is the donatur landing page (`/`).
- `components/layout/` — Navbar, Footer (shared across all pages).
- `components/sections/` — landing page sections (Hero, Program, Kalkulator Zakat, FAQ).
- `public/images/` — static assets (logo, hero photo, program photos).
